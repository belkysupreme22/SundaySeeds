# SundaySeeds profile portraits

The bundled sprite is a 4-by-3 sheet of fictional cartoon adults created with
the built-in image generation tool. It is packaged as a 1024-by-768 JPEG.
The stable avatar IDs in `src/features/profile/types/avatar.ts` follow the
sheet's row-major order. The app clips each selected tile into the avatar frame.

Textile direction references [Divine Netela](https://museum.gwu.edu/cotsen-textile-traces-talk-divine-netela).
