The standard for shipping a screen

  • Shared tokens, typography roles and canonical components; no new one-off palette.
  • Check default, focused, selected, pressed, disabled, pending, success, error and empty states.
  • Review 320/390px layouts, 150%/200% text, keyboard/safe areas and mixed English–Amharic text.
  • Normal text contrast ≥4.5:1; relevant large text and control indicators ≥3:1. State also has text or shape.
  • 44pt minimum touch targets; prefer 48dp. Reduced motion, backgrounding and cancellation have explicit behavior.
  • Auth, Settings and first-run routes retain Back, Skip, error recovery and their original data boundaries.
  • Owner runtime/native review remains pending. Token calculations, specimens and source inspection do not certify the app.
