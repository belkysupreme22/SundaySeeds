# Account typography comparison assets

The [design guide](../guide.html#auth-type-options) uses local specimens for
the following candidates. `SOURCES.json` pins the exact files and records
checksums. The font files are upstream binaries. The license text uses LF line
endings with trailing whitespace trimmed.

| Candidate | What to compare |
| --- | --- |
| Lexend | English heading, supporting copy and button at 400 and 600 |
| Waldba Fantuwua | Flat stroke ends and single-wing serifs for a print-like heading |
| Waldba Zelan | Rounded ends for a softer Amharic sans face alongside Lexend |
| Waldba Tint | Ornate blackletter for short titles |

The Waldba snapshots are Raey Type's Unicode preservation work derived from the
Senamirmir WashRa collection. The guide uses plain modern Amharic. Any app
adoption needs wider text coverage and a native layout review. These files are
loaded by the local guide as candidates; the app uses its existing font roles.
[Raey Type collection](https://github.com/raeytype/waldba-font-collection)
[Google Fonts Lexend source](https://github.com/google/fonts/tree/main/ofl/lexend)
