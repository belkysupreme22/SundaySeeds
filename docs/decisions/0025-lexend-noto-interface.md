# 0025. Lexend and Noto for the mobile interface

Date 5 November 2026.

After reviewing the bilingual specimens, the owner selected Lexend for English
and Noto for Amharic. Interface text uses Lexend or Noto Sans Ethiopic by script.
Account headings use their respective semibold cuts. The four Lexend weights
are static upstream files loaded with the existing Expo font gate.
[Upstream static Lexend assets](https://github.com/googlefonts/lexend/tree/7894f02b2e7eabc48595f1d4eff3b17b48c6e651/fonts/lexend/ttf)

Long lesson text has an editorial reading role with Source Serif 4 and Noto
Serif Ethiopic. Geez Gofa Mono C accents selected Amharic labels. The
[manuscript research](0024-ethiopic-auth-typography.md) records the earlier
account heading exploration. [Guide specimens](../design-system/guide.html#auth-type-options)

Review startup text, auth, Home, and bottom navigation on narrow screens in both
languages at larger text sizes. Check mixed-script labels and editable names,
where native text-input fallback is platform-dependent.
